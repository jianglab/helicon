# Report a problem or ask for a feature

Something not working, unclear, or missing? Please tell us on the
[issue tracker](https://github.com/jianglab/helicon/issues/new): a clear report is the quickest way to
get it fixed, and a question that you had is likely to be one that others have.

## Include

1. **The version.** Run

   ```sh
   helicon --version
   ```

   and paste the line it prints (for example `helicon 2026.10 (a1b2c3d)`; for a development version, the
   commit is in the brackets). Also say how you installed Helicon (conda, pip, a git checkout), your
   operating system, and `python --version`.
2. **Where it happened:** the web app (which tab), the file browser, or the command-line program (the full
   command you typed).
3. **What you did, step by step,** and what you expected to see. For an app, the data you loaded: a public
   data set (EMPIAR or EMDB id) is best.
4. **What you saw instead:** the error message, and a screenshot. For the web apps and the file
   browser, the text in the **terminal** where you started Helicon is the most useful thing to add: copy
   it from the start to the error.
5. **A small example file,** if the problem depends on your data and you can share a piece of it. Do not
   post data that are not yours to share.

For a feature request, say what you are trying to do, not only what you would like the program to do: it
helps to find the best way.

## Before you report

- [Notes and answers](notes.md) lists the common questions.
- Update to the newest release (`helicon update`; see [Install](install.md)): the problem may already be
  fixed.
- Search the [open and closed issues](https://github.com/jianglab/helicon/issues?q=is%3Aissue): someone
  may have met it before.
