# webCalEM

Open the web app WebCalEM, which calibrates the magnification (pixel size) of a TEM.

Opens <https://jianglab.github.io/WebCalEM/> in your browser. With `--printUrl` it only prints the
address.

## Options

```text
usage: helicon webCalEM [-h] [--printUrl]

A Web app that calibrates the magnification (pixel size) of a TEM

options:
  -h, --help  show this help message and exit
  --printUrl  only print the web address of WebCalEM, do not open a browser
```
