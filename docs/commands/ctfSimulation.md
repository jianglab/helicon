# ctfSimulation

Simulate 1D and 2D TEM contrast transfer functions.

(Needs `helicon[streamlit]`; see [Install](../install.md).)

Starts a Streamlit app in your browser.

## Options

```text
usage: helicon ctfSimulation [-h]

A Web app that simulates 1D/2D TEM contrast transfer function (CTF)

options:
  -h, --help  show this help message and exit
```
