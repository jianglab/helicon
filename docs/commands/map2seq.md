# map2seq

Find the protein sequence that best explains a 3D density map.

(Needs `helicon[streamlit]`; see [Install](../install.md).)

Starts a Streamlit app in your browser.

## Options

```text
usage: helicon map2seq [-h]

A Web app that identifies the best protein sequence explaining a 3D density map

options:
  -h, --help  show this help message and exit
```
