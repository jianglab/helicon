# procart

Plot cartoon illustrations of residue properties of amyloid atomic models.

(Needs `helicon[streamlit]`; see [Install](../install.md).)

Starts a Streamlit app in your browser.

## Options

```text
usage: helicon procart [-h]

A Web app that plots cartoon illustration of the residue properties of amyloid atomic models

options:
  -h, --help  show this help message and exit
```
